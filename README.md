# elijahtramm.github.io

Personal academic website, built with Jekyll using the [Dumbarton](https://github.com/tcbutler320/Jekyll-Theme-Dumbarton) theme (MIT license, see LICENSE.txt).

- Home page text: `index.md`
- Education: `_data/education.yml`
- Publications: `_bibliography/papers.bib`
- Navigation links: `_data/nav.yml`
- Name, links, colors: `_config.yml` and `_data/themes.yml`

Every push to `main` rebuilds and publishes the site via `.github/workflows/pages.yml`.
